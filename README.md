# Pynex TPO SaaS

Multi-Tenant B2B Placement & Training Portal for colleges and universities.

## Overview
Bridging the gap between college Training & Placement Offices (TPO) and students.

### User Roles
- **Super Admin**: Tenant management, global metrics, quota allocations.
- **TPO Admin**: Placement drives, student eligibility tracking, archival matrix.
- **Student**: Eligibility verification, drive registrations, application tracking.
